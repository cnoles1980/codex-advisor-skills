# Current State

AI Matrix Map is currently a strong editorial product foundation, not yet a full intelligence platform.

Current product shape:

- desktop matrix and mobile accordion UI
- dedicated company pages
- company directory
- normalized local JSON dataset
- public contribution flow
- source-checking script
- Notion-backed editorial workflow with sync and publish scripts

Current primary categories:

- frontier labs
- open-weight labs
- media models
- physical AI
- agentic coding tools
- vertical and enterprise companies
- academic and nonprofit research groups

Known roadmap ideas from the repo:

- compare mode for company-vs-company analysis
- separate model and event layers from organizations
- adapters for Hugging Face, GitHub releases, arXiv, official blogs, and related sources
- review queue so source changes are approved before they appear in the UI

Editorial workflow implied by docs:

- editors work in Notion
- site publishes from local JSON for speed and rollback
- sync writes reports
- publish scripts can auto-publish only when today's changes exist

Interpretation:

- the product already has a credible content and publishing backbone
- the next risks are not "can this be built" but "what creates repeat use and defensible value"
- trust, freshness, and taxonomy quality are core product elements
